# Proposed Tasks

[Browse Observatory proposals](https://github.com/Kgray44/Aetherwake/tree/observatory-proposed-tasks/Proposed%20Tasks).

The owner-private Observatory accepts engineering proposals and publishes public v1 Task JSON files to this folder on the `observatory-proposed-tasks` branch. Files use task IDs as filenames and begin in `proposed`, with owner acceptance `not_reviewed`. Review and promotion into the engineering harness remain separate.

Submit only material suitable for this public repository. Credentials, raw execution logs, private telemetry, and sanitized execution projections belong outside this folder.
