# A0 Windows native baseline

This ledger records Windows x64 runs on November 9, 2026, with Node 24.18.0, the lockfile Electron, MSVC and an interactive desktop. Tests used disposable synthetic canonical data. The exact commits are [`fc9827e`](https://github.com/Kgray44/Aetherwake/commit/fc9827e5187db7f9c93b7cc6fbf2339c2c6b95a5) and [`e9bee66`](https://github.com/Kgray44/Aetherwake/commit/e9bee66285a09936513e17c0a0e3bf89b6f5df2c). The final candidate may include later test, CI and evidence changes. See the [draft PR](https://github.com/Kgray44/Aetherwake/pull/25) for its head and hosted checks.

**Expanded application.** Run `npm --prefix prototypes/visual-experience/cinematic-v3 run verify:application`. The runner records typecheck, Windows build, profile preparation, initial journey and same-profile restore. Terminal JSON names the private runner receipt and the per-stage native evidence. At `fc9827e` all five stages passed. The initial journey recorded 12 checks over 23 steps and the restart recorded one check over two steps. Both renderer error counts were zero.

**Living Instruments.** After a clean Windows build, run `node --experimental-strip-types scripts/verify-living-instruments-native.mjs`. Use `--mission-only` or `--family-only` for the focused runs. Each prints its private `living-instruments-evidence/journey.json` location. At `fc9827e` the default run passed seven of nine checks. Its planning check timed out with an unsaved Timeline orientation, so the restart check had no initial planning result. The failed receipt was retained. At `e9bee66`, the repaired default run passed all nine checks, the mission run passed six, and the family run passed five. No provider execution was recorded in these runs.

**Focused reruns.** From the desktop package, use Electron with `--integration-checklists --profile=<fresh absolute C: profile named review-checklists-DIGITS>` and the same profile with `--verify-restore` for the restart. At [`6a3d0bc`](https://github.com/Kgray44/Aetherwake/commit/6a3d0bc307f71ffea731121ca59af18925bc38f4) the initial journey passed. The restore stopped after focus loss. The focused offline AIR command uses `--integration-vela --verify-air-local --verification-deadline-ms=85000 --profile=<fresh absolute profile named review-vela-air-offline-DIGITS>`. The prior run observed the local answers but failed while comparing renderer and canonical history. The harness now waits for exact agreement. The next run at [`e800e01`](https://github.com/Kgray44/Aetherwake/commit/e800e01d618a705c60321d5b9af8496e121b4815) aborted after focus loss. The expanded journey also retained a focus-loss result at that commit. The runners stopped without reclaiming the desktop. Failed and partial receipts remain in private evidence.
