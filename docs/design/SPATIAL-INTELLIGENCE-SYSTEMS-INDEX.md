## Four distinct connected perspectives

| Perspective | Purpose | What it is not |
|---|---|---|
| Workspace | Create, organize and operate on project resources and conversations | Not a substitute for global awareness |
| Constellation | Spatial relationship/navigation among projects/workspaces | Not a fabricated execution trace |
| Intelligence Stream V2 | Full-screen plan-first execution landscape for *one project*, with branch fronts and Activity Theater | Not a vertical list of blocks; not Vela's private mind |
| Vela Presence | Global GPU-native living central Intelligence Nebula reaching into six 3D domain nebulas; real activity motes | Not a 2D blob, radial menu, flowchart or literal thoughts |

The floating Active Projects Dock uses one small pill per currently relevant project. Primary action opens its workspace, secondary action its Stream. Multiple projects trigger a compact selector when entering Stream; direct switching inside a Stream must work. All perspectives use one canonical source-trace truth model.

## How Codex should use this package

First: check the current PR #19/#20 code and branch heads, governance registry, and the exact source-owned execution/trace and Motion Coordinator implementations. Do not create an independent truth bus, duplicate Vela identity or overwrite a concurrent worker's checkout.

Second: follow the phased acceptance plan. **Prototype the final GPU 3D nebula and organic tendril behavior before committing to broad integration.** Compare moving-camera evidence to the supplied reference with the owner. Reject a pretty sphere, blue jellyfish, static smoke plane, radial menu, or a glowing line disconnected from central volume.

Third: build shared typed contracts, then integrate both new projections. A graph with animated branches is insufficient unless it is the full-screen project execution landscape, plan-first and source-backed. A glowing Vela scene is insufficient unless it is actual three-dimensional GPU geometry with interior light and material continuity.

Fourth: deliver native proof and accurate results. Separate synthetic fixture demonstrations from real provider/tool execution, and keep verified outcomes independent of estimates or particle movement.

- Actual GPU-native three-dimensional spatial volume, not 2D tricks.
- Faithful material/morphology against the exact user's nebula image; not merely similar palette.
- Central cloud visibly stretches its own matter, veils and inner light into neighboring domain clouds; three concurrent bridges.
- Plan-first project Stream with grayed future work, real concurrency, smoothly changing luminous fronts and verified source-driven completion.
- Bottom-right Activity Theater presenting actual current operation content in motion.
- Compact floating active-project pills, accurate time/status, workspace primary action and direct Stream switching.
- Presence↔Stream and Stream A↔B spatial travel, no disconnected page swaps.
- One canonical authorization-aware event/plan source and accessible fallback.
- Reproducible videos, measured GPU/performance traces and explicit owner artistic acceptance.
