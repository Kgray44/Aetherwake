| Presentation | Primary interaction | Contextual depth |
| --- | --- | --- |
| Quick switcher | A bounded recent/favorite/current-project conversation list; keyboard search and the same canonical open operation. | Quick creation; observed running state. It is a manager navigation surface, not a second universal command system. |
| Conversation library | Conversation-first browse, then explicitly scoped/grouped search. Native collapsible project and nested collection branches provide location. | Sort/filter, manual-versus-smart membership, archive and existing organization controls on demand. |
| Workspace/focused chat | Keep the same shared editor/session and actual provider observations. | Root/Universal own placement and Motion Coordinator transitions; CP supplies navigation/state hooks only. |

Use existing decorated summaries/buttons, native disclosure/keyboard behavior and the established glass hierarchy. Titles lead; location, activity and provider follow; technical IDs remain inspectable. No independent animation scheduler, permanent settings wall or optimistic mutation success.

## Released source behavior and verification

The CP source now implements conversation-only empty global browse; explicit result types; exact message hits grouped under a conversation with three previews and further matches on demand; recent activity/creation/title/running-first sorting; native collapsible project/collection hierarchy; visible manual-versus-smart membership; a bounded 12-entry quick switcher using the same canonical open operation; compact parent/current/child/sibling branch navigation and exact fork-source links; optional creation title; returned-ID smart-save; and serialized latest navigation intents instead of silently dropping them while a read runs. Folder creation under a selected folder uses the canonical parent rule; it is not a bulk transaction or an undo implementation.

Root's existing trusted ChatGPT/reference opening hook and unavailable native-account fidelity disclosure are preserved. The later owner decision authorizes a separate eligible SIWC inference provider; it does not change native account history/memory/sync support. Provider/auth and Personal Context Engine implementation remain separately owned. This slice neither authorizes a provider nor copies a personality or memory store.

`CanonicalConversationHost.canonicalReadView` is optional, trusted, in-process and uses the same canonical graph. Its named readonly shape contains metadata instead of a forged partial Snapshot. Resource bodies and message timestamps/source IDs are lazy callbacks that must enforce current source access. Bounded list metadata uses the existing canonical lineage traversal: incomplete/denied coverage produces `messageCount: null` and `lastActivityAt: null`, with an explicit coverage status. Detail still reports its actual authorized materialized count. The compatibility fallback still clones full backend/desktop snapshots, and detail/content search still materialize history; these paths are not claimed to scale.

Executed source evidence: 100 component/service/adapter/draft-session tests plus 4 explicitly selected SQLite draft migration/CAS/access/independence tests pass; strict TypeScript across CP source/tests and stylesheet parsing pass. The two unchanged draft aggregate-capacity/row-retention stress cases are excluded from this release's reported focused coverage; only captured terminal passes are counted. Nine new mounted tests cover grouped exact hits, real folder nesting and canonical parent scope, switcher keyboard/bounds, explicit local identity on creation refusal, queued latest opens, close during a read, duplicate collection titles and truthful compact lineage. SQLite tests cover activity/search modes/restart, exact provider-observation identity and a same-graph no-cloning projection with zero denied-source body reads. Eligible inference is marked implementation-in-progress with authorization/live inference unverified; it remains separate from native account fidelity. These are synthetic CPU/SQLite checks, not first meaningful paint, native input, artistic review, model inference or account verification.
