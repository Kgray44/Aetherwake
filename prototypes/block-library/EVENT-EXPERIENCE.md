# Recorded Intelligence Stream experience

The actual Stream card now mounts `mountEventExperience` over the same canonical replay and native event subscription already used by the desktop. It owns no event database, provider, inference turn, timer loop or GPU context. The application cache remains bounded to 250 canonical records; expanded cards render up to 100 keyed rows. Hidden and compact cards skip detailed DOM work, and a shared compact summary uses actual recent event types and evidence classes. Open event details keep their node when a new record arrives.

The user can filter by received-after time, evidence class, provider, resource, execution ID, metadata text, current workspace resource membership or current project resource membership. Scope wording explicitly distinguishes current membership from membership at capture. Records referring to currently unavailable resources are excluded from this view; this does not delete journal records. An unavailable selected filter remains selected and empty rather than silently broadening to all records.

Metadata inspection uses an explicit allowlist of actual event/resource/execution/native identities, received/provider timestamps, provenance/correlation/causation and already redacted byte/item metadata. Provider response deltas, private tool payloads and reasoning are not serialized into the detail view. Observed, reported, inferred and simulated classifications remain unchanged. Missing fields display Unavailable, including provider timing. Related-resource opening reuses canonical navigation/editor actions; there are no controls that approve provider actions from journal content.

A replay metadata read locates the latest journal cursor before requesting a bounded recent page. This fixes the prior initial read, which could show the first default replay page while describing it as latest activity. The view distinguishes retained-journal truncation, the smaller local window, pre-capture uncertainty, captured gap/reorder/reconnect markers and an actual backend-disconnected notification. It does not invent activity in uncaptured intervals. Refresh is explicit; no polling was added.

Authority routing selected Constitution 00 (binding), and published advisory charters 09,14,15. Relevant advisory concepts are AW-OBS-022 through027 (shared identity/filter scope), AW-TRUST-110 through116 (private details/evidence gaps) and AW-QVA-071 through079 (evidence classes, loss and temporal integrity). This implementation does not claim those entire charters are accepted or completely implemented.

Four source tests cover the tail replay request, actual class/source/resource/execution/time intersections, current membership and unavailable-resource filtering, input/identity preservation and the metadata allowlist excluding private output. The whole library suite passes40 tests; App TypeScript and visual-app source tests also pass. Actual native stream filtering/detail/lifecycle acceptance still belongs to the integrated desktop run.
