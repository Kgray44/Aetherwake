# Manifestation host adapter

`createVelaManifestation({motion,root,wake,resize})` lives in cinematic-v3's `src/vela-manifestation.ts`. It is an isolated browser-only observer, with no provider, command, storage or independent scheduler. Root owns App/Main wiring and native appearance acceptance.

- Forward the real panel `onManifestation(value|null)` into `observe`. `root` is the existing contextual content host. `null` drops the panel-node references immediately and disconnects ResizeObserver.
- Call `frame(policy)` from the existing Motion Coordinator application frame, including while its bounded close fade settles. It coalesces dirty measurements and calls the existing contextual `resize` only when the wanted size changes. `size()` returns the last preferred size for surface opening.
- Call `afterRender({x,y,width,height})` **after the actual production Environment draw**, converting its actual `presenceBounds()` fields `w/h` to `width/height`. Never substitute the DOM hit target, saved placement, target pose, synthetic origin or an old observation. The adapter measures the real host rectangle in that callback and uses the existing pure `manifestationGeometry`.
- On actual surface close call `panel.close()` (which emits null); on destruction call `dispose()`. It disconnects the observer, removes its one optional MC body and fixed SVG, and leaves every other MC body untouched.

The bridge is a pointer/ARIA-hidden body-level fixed SVG at z999999, below the existing contextual layer at1000000 and outside the panel's reading clip. Only its decorative opacity uses MC. No editor, message, action, canonical state, caret, focus, scroll position, content opacity or content transform is modified. Initial history is a baseline; new optical reveal cannot gate ready content. Quiet/reduced policies reconcile immediately and skip closing fade. Hidden/graphics-unavailable policies hide and retire optics immediately; CPU content sizing still works with graphics unavailable. Invalid, overlapping and wholly offscreen geometry has no bridge; the pure geometry's bounded partly clipped attachments remain based on their real origin.

Sizing uses measured nonshrinking direct reading groups, composer and visible feedback, not the stretched reading viewport's scrollHeight. Preferred width families are360 for minimal/Whisper,480 for Insight and520 for Action/history/context, bounded to280..560. Actual measured height is bounded to110..640; the contextual host remains responsible for viewport/safe-area clamping. ResizeObserver only marks dirty and wakes the existing frame. Repeated delivery or its own host resize does not rewrite an unchanged wanted size. Content is visible and interactive independently of callback/resize success.

Integrate one sizing/reveal owner: the old `createVelaExperience` content-arrival transforms/opacity and fixed sizing must not compete with this adapter. Any retained phase observation must remain observational and must not fade ready messages/actions. This release deliberately changes no existing App/Main/CSS files.

The synthetic DOM/MC/geometry tests establish source behavior and cleanup, not actual browser layout, GPU completion, monitor presentation, motion quality or artistic/native acceptance. `diagnostics()` exposes bounded geometry/input/counter/size state, never message bodies. Root must bind actual source/assets, fresh production draw, visible text/controls and physical input in subsequent native checks.
